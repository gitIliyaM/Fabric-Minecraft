MessageMod для Minecraft Fabric

Мод для Minecraft, позволяющий игрокам отправлять и сохранять сообщения в базе данных PostgreSQL

Обзор
MessageMod - это модификация для Minecraft на базе Fabric, которая позволяет игрокам отправлять сообщения,
сохраняющиеся в базе данных PostgreSQL с использованием Hibernate ORM. Идеально подходит для серверов, 
где нужно вести лог сообщений, отслеживать общение игроков или создавать пользовательские системы чата.

Возможности
Встроенный интерфейс - Удобный экран для ввода сообщений
Сохранение в БД - Сообщения хранятся в PostgreSQL
Привязка к игрокам - Сообщения связаны с UUID игроков
Горячие клавиши - Настраиваемая клавиша для открытия интерфейса
Логирование - Подробное логирование операций
Оптимизация - Использование HikariCP для пула соединений

Технологии
Minecraft 1.21 с Fabric Loader
PostgreSQL - система управления базами данных
Hibernate ORM 6.6.3 - объектно-реляционное отображение
HikariCP - пул соединений с базой данных
Fabric API - модификация игры

Использование
Запустите Minecraft с установленным модом
Нажмите клавишу M (англ. по умолчанию) или Ь (русская по умолчанию) для открытия интерфейса сообщений
Введите сообщение (до 256 символов)
Нажмите "Отправить" - сообщение сохранится в базе данных

Конфигурация
Настройка базы данных
Файл resources/hibernate.cfg.xml содержит все настройки подключения:
URL базы данных
Имя пользователя и пароль
Настройки пула соединений
Параметры диалекта PostgreSQL

Структура базы данных
Таблица messages:
CREATE TABLE messages (
id SERIAL PRIMARY KEY,
uuid UUID NOT NULL,
text VARCHAR(256) NOT NULL,
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Поиск и устранение неисправностей
Проблемы с подключением к БД
Проверьте запущен ли PostgreSQL
Убедитесь в правильности настроек в hibernate.cfg.xml
Проверьте логи на наличие ошибок подключения

Мод не загружается
Убедитесь что установлены Fabric API
Проверьте совместимость версий Minecraft
Проверьте логи загрузки модов
