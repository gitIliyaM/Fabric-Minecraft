MessageMod для Minecraft Fabric. <br>

Мод для Minecraft, позволяющий игрокам отправлять и сохранять сообщения в базе данных PostgreSQL <br>

Обзор <br>
MessageMod - это модификация для Minecraft на базе Fabric, которая позволяет игрокам отправлять сообщения, <br>
сохраняющиеся в базе данных PostgreSQL с использованием Hibernate ORM. Идеально подходит для серверов, <br>
где нужно вести лог сообщений, отслеживать общение игроков или создавать пользовательские системы чата. <br>

Возможности <br> 
Встроенный интерфейс - Удобный экран для ввода сообщений <br>
Сохранение в БД - Сообщения хранятся в PostgreSQL <br>
Привязка к игрокам - Сообщения связаны с UUID игроков <br>
Горячие клавиши - Настраиваемая клавиша для открытия интерфейса <br>
Логирование - Подробное логирование операций <br>
Оптимизация - Использование HikariCP для пула соединений <br>

Технологии <br>
Minecraft 1.21 с Fabric Loader <br> 
PostgreSQL - система управления базами данных <br>
Hibernate ORM 6.6.3 - объектно-реляционное отображение <br>
HikariCP - пул соединений с базой данных <br>
Fabric API - модификация игры <br>

Установка <br>
Требования <br>
Minecraft 1.21 <br> 
Fabric Loader <br>
PostgreSQL сервер <br>
Java 21 <br>

Использование <br>
Запустите Minecraft с установленным модом <br>
Нажмите клавишу M (англ. по умолчанию) или Ь (русская по умолчанию) для открытия интерфейса сообщений v
Введите сообщение (до 256 символов) <br>
Нажмите "Отправить" - сообщение сохранится в базе данных <br>

Конфигурация <br>
Настройка базы данных <br>
Файл resources/hibernate.cfg.xml содержит все настройки подключения: <br>
URL базы данных <br>
Имя пользователя и пароль <br>
Настройки пула соединений <br>
Параметры диалекта PostgreSQL <br>

Структура базы данных <br>
Таблица messages: <br>
CREATE TABLE messages ( <br>
id SERIAL PRIMARY KEY, <br>
uuid UUID NOT NULL, <br>
text VARCHAR(256) NOT NULL, <br>
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP <br>
); <br>

Поиск и устранение неисправностей <br>
Проблемы с подключением к БД <br>
Проверьте запущен ли PostgreSQL  <br>
Убедитесь в правильности настроек в hibernate.cfg.xml <br>
Проверьте логи на наличие ошибок подключения <br>
 
Мод не загружается <br>
Убедитесь что установлены Fabric API <br>
Проверьте совместимость версий Minecraft <br>
Проверьте логи загрузки модов <br>
